Install Scripts Controller has been installed.

Check pods:
  kubectl get pods -l app.kubernetes.io/instance={{ .Release.Name }}

Get the application URL:
  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "install-scripts-controller.fullname" . }} 1325:{{ .Values.service.port }}
  Then open http://localhost:1325

Sign in with the password set via secrets.password.
Install links are generated in the UI; each embeds a random auth key that
rotates every {{ .Values.config.installKeyTTL }}.
